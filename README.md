# 时光村落 · Timegrove

一个使用学习与休息打卡经营村庄的中文网站。真正的低多边形 Three.js 3D 场景，适配手机和桌面，无后端、无账户、无付费抽奖、无外部运行时请求。

## 使用

底部导航栏以「村庄」「计时」两项为主；右侧三个小图标依次是手记、奇物（星砂寻宝 / 奇物柜，页内分段切换）和更多（自由建造、建筑管理、存档与规则）。村庄与计时两屏可上下滑动切换；手机上其余页面铺满导航栏以上的区域，通过导航栏切换，其他弹窗以底部面板形式弹出。横向拖动村庄用于旋转 3D 视角，点击 3D 建筑可进入建筑管理。切换页面不会中断计时或更换存档。

1. 选择 25 / 45 / 60 分钟，填写学习内容并开始计时。支持暂停、继续、刷新恢复；到点停止累计，点击「结束并打卡」后发放奖励。
2. 已完成的学习可补记 1–240 分钟，指定结束时间。拒绝未来记录、重复时间和与已保存记录重叠的时间。
3. 每分钟学习获得 2 木材、1 石料、0.4 星砂。累计每学习 60 分钟增加 1 位居民。
4. 每学习 5 分钟解锁 1 分钟有奖励的休息，每分钟获得 2 补给、0.2 星砂。休息计时为 5 / 10 / 15 分钟，自动受可用奖励时长限制。
5. 村庄从 3 位居民、Lv.1 林间书屋和 Lv.1 森林工坊起步，赠送 120 木材、80 石料、30 补给、30 星砂。所有学习统计从零开始。
6. 十三种设施可建设、升级至 Lv.5。每级每小时产出：书屋 2 星砂、工坊 18 木材、采石场 12 石料、农场 10 补给、天文台 5 星砂；v2 新增渔人码头 14 补给（需 4 位居民、靠海两格内）、麦香面包坊 12 补给（5 位）、陶土窑 16 石料（5 位）、林场木屋 24 木材（6 位）、溪畔茶屋 3 星砂（7 位）、海角灯塔 6 星砂（9 位、靠海，占 1 格）、星辉图书馆 7 星砂（10 位，占 3×3）、时光钟楼 9 星砂（14 位）。建造/升级费用为基础成本乘以 1.65 的当前等级次方，逐项向上取整。
   - **自由建造（v2）**：村庄面板「建造」进入全屏建造模式。自行选择建筑位置与朝向，已建成的建筑可免费移动/旋转；20 种装饰（树木、花圃、路灯、水井、木桥、小帆船、星辉雕像、奇物展台等）可反复放置，拆除不返还资源。
   - **岛屿地貌（v2）**：28×28 格地图。填海造地（石料/木材/补给，随扩建面积递增）、草地/沙滩/花甸/岩地/石径/池塘笔刷、抬升（石料）与降低、还原为海。建筑需要同高度的陆地，水面只能放木桥/小帆船。
7. 离线生产按时间结算，仓库最多储存当前产速下 24 小时的未领取资源。升级前先按旧产速结算。
8. 收藏品共 18 件（寻常 6、稀有 5、史诗 4、传说 3），均有可旋转查看的 3D 模型，可放到「奇物展台」上在村庄中展示。寻宝每次 30 星砂，寻常 60%、稀有 28%、史诗 10%、传说 2%；连续 19 次未获得史诗/传说后，第 20 次最低史诗。重复收藏保留数量。同一稀有度内均匀随机，使用浏览器加密随机数。
   - **星砂寻宝 / 奇物柜（v2.2）**：寻宝与收藏分为两个页面。寻宝时播放全屏流星动画：流星在途中变为本次最高稀有度的颜色（绿·寻常、蓝·稀有、紫·史诗、金·传说），撞击后逐件 3D 揭晓，五连抽最后显示汇总卡片；可随时跳过，抽取结果在动画开始前已保存。奇物柜按稀有度筛选，未获得的奇物显示为剪影。最近寻宝记录仅保存在本设备。

## 提醒

- **到点提醒**：计时结束时播放提示音、手机震动（支持的设备），标签页标题实时显示倒计时；可在计时页开启系统通知（页面需保持在后台打开；iPhone 需先添加到主屏幕，且切到后台时 Safari 会暂停网页，通知可能等回到页面时才出现）。
- **备份提醒**：距上次导出超过设定天数（默认每周，可选 3 天 / 两周 / 关闭）且期间新增学习满 1 小时，村庄页会出现备份卡片。手机上导出会调用系统分享面板，可直接存到「文件」/ iCloud / 网盘。提醒设置只保存在本设备，不写入存档。

## 存档兼容（v2）

- 存档版本升为 2，localStorage 键不变。旧版（v1）存档在首次打开新版时自动无损迁移：资源、学习记录、计时、建筑等级、收藏与保底计数全部保留，五座原有建筑放在与旧版一致的位置，并自动生成默认岛屿与原有树木/栅栏。
- 迁移前会把原始 v1 存档另存到 `timegrove-save-v1-backup-before-v2`（只写一次）。导入功能同时接受 v1 与 v2 存档文件。
- 新版存档无法被旧版页面读取（旧版会提示存档不兼容并停止写入，不会覆盖）。
- 所有既有数值规则（学习/休息奖励、产速、升级费用、离线上限、抽奖概率与保底）保持不变。

## 数据与时间

- 所有数据仅在当前域名、当前浏览器的 localStorage 中保存。没有云同步；手机/电脑、不同浏览器、不同部署域名各有独立存档。
- 「存档与规则」提供 JSON 导出与导入。导入先验证，再询问是否替换；不会合并存档。
- 清理浏览器网站数据会丢失进度，请定期导出。GitHub 仓库与 Pages 不保存个人学习记录。
- 本周按设备本地时区从周一 00:00 统计；跨日/跨周的学习按真实活跃时间区间拆分，暂停时间不算。更改设备时区会改变周边界。
- 距离上次打卡采用最近一次学习的实际结束时间，补记不会把历史学习伪装为刚结束。
- 刷新或关闭网页后，正在进行的计时继续按时钟推算，最多累计预定时长；不会整夜无限计时。它是自律工具，不会检测使用者是否真的在学习。
- 使用 Web Locks 协调支持该标准的浏览器中的多个标签页，避免重复领奖；不支持 Web Locks 的旧浏览器请只保留一个页面。
- 所有数值及本机时间可以由用户自行修改；本项目适用于个人习惯培养，不适合作为考试、考勤或现金奖励的防作弊凭证。
- 3D 不可用时，学习、建设和收藏仍可使用；减少动态效果的系统偏好会关闭居民与风车动画。

## 本地运行

```sh
python3 -m http.server 4173 --directory dist
```

打开 `http://localhost:4173`。请使用 HTTP 服务运行，不要直接双击 HTML（浏览器会限制本地 ES 模块）。运行单元验证：`npm test`；格式化：`npm run format`（Prettier 3.3.3，按需通过 npx 下载），只需 Node.js 18+，无需安装依赖。

## GitHub Pages 部署

1. 将完整项目上传到 `study-village` 仓库的 `main` 分支。
2. 打开仓库 **Settings → Pages → Build and deployment → Source → GitHub Actions**。
3. 打开 **Actions → Deploy Timegrove to GitHub Pages → Run workflow**；后续向 main 推送会自动发布。
4. 待工作流成功后，地址通常为 `https://2357-qaz.github.io/study-village/`，以 Pages 设置显示的 URL 为准。

仓库权限或套餐需允许 Pages。公共仓库适合直接使用；本项目不需要配置密钥。也可将 `dist/` 内文件上传到仓库根目录后选择分支根目录部署。

## 文件

- `dist/index.html`、`dist/style.css`：响应式界面。
- `dist/core.js`：纯函数规则、统计、计时、存档验证。
- `dist/app.js`：入口，组装各功能模块、启动定时刷新、加载 3D 村庄与可选只读 WebMCP 状态工具。
- `dist/ui/`：界面按功能拆分的模块。`store.js` 负责存档读写、事务（Web Locks）、共享状态与通用工具，其余模块通过 `onRender()` 注册各自的渲染：`nav.js` 页面切换、`home.js` 村庄概览、`timer.js` 计时与补记、`buildings.js` 建筑管理、`journal.js` 学习手记、`collection.js` 奇物柜与寻宝、`thumbs.js` 收藏品缩略图、`save.js` 存档导入导出与备份提醒、`build.js` 建造模式。
- `dist/scene.js`：3D 场景：地形网格烘焙、海洋、昼夜光照（按本机时间）、居民寻路、建造模式手势与拾取。
- `dist/models.js`：程序化低多边形模型（13 座建筑×5 级细节、20 种装饰、居民、18 件收藏品），静态部分合并为少量网格绘制。
- `dist/wish.js`：寻宝全屏动画（Canvas 星空与流星、揭晓、汇总、合成音效）。
- `dist/alerts.js`、`dist/sw.js`：到点提醒与备份提醒；仅用于通知的极简 Service Worker（不缓存页面）。
- `dist/items3d.js`：收藏品缩略图与可拖动旋转的 3D 查看器。
- `docs/v2-spec.md`：v2 规则与接口规格。
- `dist/vendor/`：随项目打包的 Three.js 0.180.0，以及按需生成的 Lucide 图标子集 `lucide-icons.js`（附原许可）。
- `tools/build-icons.mjs`：扫描源码中用到的图标，从 `tools/lucide-full.min.js` 生成图标子集；新增图标后运行 `npm run icons`（`npm test` 会检查子集是否同步）。
- `tests/core.test.mjs`：奖励、统计、跨周、计时、存档、离线产出、抽奖保底，以及 v1→v2 迁移、放置/地貌/装饰规则验证（22 项）。
- `.github/workflows/pages.yml`：GitHub Pages 发布流程。

本项目的 3D 场景为程序化模型，无远程图片与字体依赖。只读 WebMCP 工具会在支持 `document.modelContext` 的浏览器中注册；普通浏览器不受影响。
